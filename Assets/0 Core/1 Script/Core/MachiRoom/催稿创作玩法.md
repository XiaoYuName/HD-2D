# 催稿创作玩法

## 1\. 功能概述

### 1\.1 功能定位

**女主画室**是游戏内核心资源（服装部件）的唯一产出场景。
核心玩法采用 **"策略定品（消耗灵感） \+ 进度管理（时间 / 催稿）"** 的模式：

1. **灵感草稿（定上限）**：玩家**主动消耗灵感值**，从不同档位的库中随机产出 "线稿图"。线稿的品质直接决定了最终产出的线稿品质池（如 S 级线稿结算仅产出S级高品质线稿）。
2. **画作推进（拿奖励）**：基于已确定的线稿，通过自然时间积累或玩家 "催稿" 来完成画作进度。
3. **状态风险**：催稿虽然快，但会大幅消耗灵感并增加压力。若灵感过低，会导致画作评分下降，甚至导致高品质线稿 "烂尾"（低分低奖）。

### 1\.2 核心规则总览

1. **两阶段流程**：

   - **阶段一（定品）**：选择消耗灵感数量 → 随机获得对应品质的线稿（决定最终结算的线稿奖励品质池）。
   - **阶段二（完工）**：积累进度至 100% → 结算评分 → 发放对应品质线稿奖励。
2. **特殊线稿机制**：

   - 普通线稿：玩家可选择【放弃】重抽（消耗新灵感）。
   - **特殊线稿**：**不可放弃**，必须完成该画作才能进行下一次创作。
3. **资源循环**：

   - **灵感值**：既是 "入场券"（做草稿），也是 "维持费"（维持高分）。
   - **行动力**：用于 "催稿"，强制增加进度，副作用是降低灵感、增加压力。

## 2\. 功能入口与权限

### 2\.1 功能入口

- **路径**：玩家别墅 → 大厅 → **工作室房间**。
- **交互**：进入工作室房间后，点击房间内的【画架】或 UI 面板上的【创作】按钮。
- **工作限制**：女主**必须在工作室房间内**才能进行所有创作相关操作，包括：

  - 画线稿（制作草稿）
  - 催稿操作
  - 自然进度增长

### 2\.2 权限规则

1. **解锁条件**：解锁 "工作室房间" 场景后即可使用。
2. **操作限制**：

   - **灵感不足**：无法点击对应的草稿档位（如 30/50/100 灵感按钮置灰）。
   - **行动力不足**：无法使用【催稿】功能。
   - **特殊线稿锁定**：当前持有特殊线稿时，【放弃】按钮隐藏或置灰，且无法开启新的草稿制作。
   - **位置限制**：女主离开工作室房间后，所有创作相关功能暂停，自然进度停止增长。

#### 3\.1\.2 评分与奖励规则

- **基础分**：由线稿品质决定（例如 S 级线稿起步 90 分，A 级起步 80 分\.\.\.）。
- **过程扣分**：当灵感值 ≤ 60 时，每进行一次进度增长（自然或催稿），总分 \-5。

### 3\.2 创作流程详解

#### 3\.2\.1 初始状态

- 女主处于空闲状态，等待玩家指令。
- UI 显示当前灵感值、行动力、压力值。
- **工作状态**：只有当女主位于工作室房间时，才能进入创作状态。

#### 3\.2\.2 阶段一：制作草稿（玩家主动）

1. 玩家选择消耗 **30 / 50 / 100** 灵感值。
2. 系统扣除灵感，播放抽卡 / 绘图动画。
3. **产出结果**：

   - **情况 A（普通线稿）**：获得一张线稿图。玩家可选择【开始绘制】或【放弃】（放弃则不进入绘制阶段，灵感已消耗不退还）。
   - **情况 B（特殊线稿）**：获得一张带有 "特殊" 标记的线稿图。**此时【放弃】按钮失效**。

#### 3\.2\.3 阶段二：画作推进

进入绘制阶段后，目标是将进度条推至 100%。

1. **自然自动创作（挂机）**：

   - **前提条件**：女主必须在工作室房间内。
   - 游戏每经过一个时间段（如 1 分钟）：

     - 进度 \+= 灵感值 ÷ 10
     - **判定**：若当前灵感 ≤ 60，画作评分 \-5。
   - **离开房间**：若女主离开工作室房间，自然进度暂停，直到返回房间后继续计算。
2. **玩家催稿（主动加速）**：

   - **前提条件**：女主必须在工作室房间内，且行动力 ≥ 1。
   - 点击【催稿】按钮（需消耗 1 点行动力）。
   - **执行逻辑**：

     - 进度 \+= 灵感值 ÷ 2 （速度远快于自然增长）。
     - **副作用**：压力值 \+20，灵感值 \-10。
     - **判定**：若扣减后灵感 ≤ 60，画作评分 \-5。
   - **视觉表现**：弹出 3 秒过场动画，展示进度条快速上涨。

#### 3\.2\.4 阶段三：结算与奖励

当进度达到 100% 时触发：

1. **弹窗展示**：画作完成界面，显示最终评分、女主状态。
2. **发放奖励**：根据最终评分，从该线稿对应的品质池中随机发放对应品质的线稿。

   - *若评分 \< 60，提示 "画作质量不佳，无收获"。*
3. **重置**：

   - 进度清零。
   - 评分重置为 100（或该线稿的基础分）。
   - 回到初始状态，等待玩家再次 "制作草稿"。

### 3\.3 异常与边界规则

1. **灵感归零**：若催稿导致灵感降为 0，后续无法再进行催稿，只能等待自然恢复灵感或使用道具，否则进度将停滞。
2. **溢出处理**：任何方式导致进度超过 100%，溢出部分直接作废，不继承到下一张。
3. **房间限制**：若女主离开工作室房间，所有创作相关操作暂停，包括：

   - 无法制作新的草稿
   - 无法进行催稿操作
   - 自然进度暂停增长

## 4\. UI 界面设计需求

### 4\.1 创作主界面

- **顶部**：资源栏（灵感、行动力、压力）。
- **中部**：画架区域。

  - 空闲时：显示三个大按钮 \[30 灵感\] \[50 灵感\] \[100 灵感\]。
  - 绘制中：显示当前线稿缩略图、进度条、\[催稿\] 按钮、\[放弃\] 按钮（特殊线稿时隐藏）。
- **底部**：状态提示文本（如 "女主不在工作室，创作已暂停"）。

### 4\.2 结算弹窗

- **标题**：画作完成！
- **内容区**：

  - 左侧：完成的画作立绘。
  - 右侧：评分大字（如 85 分）、获得的画稿进入画稿库。
- **按钮**：\[收下\]（点击关闭弹窗）。

## 5\. 技术实现要点

### 5\.1 状态管理

1. **全局状态**：需要维护女主的当前位置状态。
2. **创作状态机**：包括空闲、制作草稿中、绘制进度中、结算中等状态。
3. **房间检测**：实时检测女主是否在工作室房间内，决定是否激活创作功能。

### 5\.2 定时器处理

1. **自然进度定时器**：只有在女主位于工作室房间且处于绘制状态时才激活。
2. **状态同步**：当女主进入或离开工作室房间时，需要同步更新 UI 状态和功能可用性。

### 5\.3 数据持久化

4. **当前创作数据**：保存当前线稿、进度、评分等信息。
5. **资源数据**：保存灵感值、行动力、压力值等资源数据。
6. **房间状态**：记录女主的当前位置信息。
